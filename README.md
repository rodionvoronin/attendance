# Посещаемость

Простое веб-приложение для учёта посещаемости групповых занятий. Работает в браузере на Windows, Mac и iPhone, синхронизирует данные через Firebase по коду доступа — без аккаунтов и входа.

- один раз загружаете список группы, дальше только отмечаете пришедших;
- дата занятия, история прошлых занятий;
- отчёт вида «25.09.2026, Присутствовали: …. Отсутствовали: ….» копируется в буфер одной кнопкой;
- несколько групп, редактирование списков;
- работает без интернета: отметки сохраняются на устройстве и отправляются, когда появится сеть.

## Установка

### 1. Репозиторий и GitHub Pages

1. Создайте на GitHub новый репозиторий, например `attendance` (можно приватный только на платном плане — для Pages на бесплатном аккаунте репозиторий должен быть публичным; данные учеников в репозиторий не попадают, они хранятся в Firebase).
2. Загрузите в него все файлы из этой папки: **Add file → Upload files**, перетащите содержимое папки (включая `.nojekyll` и папку `icons`), **Commit changes**.
3. **Settings → Pages → Build and deployment**: Source — *Deploy from a branch*, Branch — `main`, папка `/ (root)`, **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/attendance/`.

На этом шаге приложение уже работает, но без синхронизации — только на одном устройстве.

### 2. Firebase (синхронизация между устройствами)

1. Откройте https://console.firebase.google.com → **Create a project** (Google Analytics можно отключить). Бесплатного тарифа Spark хватает с огромным запасом.
2. **Build → Firestore Database → Create database** → выберите регион (например, `eur3`) → *Start in production mode*.
3. Во вкладке **Rules** замените содержимое на текст из файла `firestore.rules` и нажмите **Publish**. Эти правила пускают к данным только того, кто знает код доступа.
4. **Project settings** (шестерёнка) → **Your apps** → значок `</>` (Web) → любое имя → **Register app**. Скопируйте объект `firebaseConfig`.
5. Вставьте значения в файл `config.js` в репозитории (на GitHub: открыть файл → карандаш → вставить → **Commit changes**).

Через минуту обновите страницу — приложение попросит код доступа. Придумайте фразу (не короче 8 символов, лучше несколько слов) и вводите её же на всех устройствах: данные будут общими. Сам код никуда не отправляется — в базе данные лежат под его хешем. Кто знает код, тот видит и меняет данные, поэтому не используйте простые коды. Если код забыт, данные под ним недоступны.

## На iPhone

Откройте сайт в Safari и введите код доступа. Можно добавить на экран «Домой»: **Поделиться → На экран «Домой»** — приложение откроется в отдельном окне с иконкой; при первом запуске оттуда код нужно будет ввести ещё раз.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | само приложение |
| `config.js` | настройки Firebase |
| `firestore.rules` | правила доступа к базе (вставляются в консоли Firebase) |
| `manifest.webmanifest`, `icons/` | иконка и режим «приложения» на телефоне |
